# Права на материалы

Пакет подготовлен для оформления корпоративных презентаций Majorpack.

## Логотипы

Логотипы скопированы без изменения геометрии из фирменных материалов, предоставленных для этой задачи. PNG получены из тех же SVG без изменения пропорций. Товарные знаки и брендовые материалы остаются собственностью правообладателей. Их присутствие в публичном репозитории не предоставляет права представляться компанией.

## Шрифт

Оригинальный образец использует Aeroport, Brownfox. Файлы шрифта не включены. Во встроенной лицензии исходных файлов есть ограничения на передачу третьим лицам и использование через веб. Пакет не предоставляет лицензию на шрифт. Использование законно доступного шрифта должно соответствовать вашим условиям лицензии.

Arial указан как переносимая замена, когда он уже доступен в среде создания презентации. Его файлы также не распространяются.

## Примеры

Макеты созданы заново с нейтральными учебными текстами. Производственные изображения, переписка, контакты сотрудников, результаты моделей, отчёты и внутренние ссылки в них не включены. Демонстрационные числовые значения подписаны как вымышленные.

## Условия

Открытая лицензия на брендовые материалы не объявляется. Для иного использования требуется разрешение соответствующего правообладателя.
